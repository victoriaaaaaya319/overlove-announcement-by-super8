# 癡情工會

阮劇團「癡情工會」會員經營相關的自動化腳本與工具。

## 目錄結構

```
1-自動化腳本/
  01-癡心情報上稿/    電子報推播上稿（Node + Playwright，把 Excel 內容建成 Super 8 群發草稿）
```

新增腳本時在 `1-自動化腳本/` 底下開 `02-…`、`03-…`，資料夾名稱用「編號-用途」，
每個腳本自己一包，含自己的 `README.md`、`package.json` 與 `.env.example`。

## 使用方式

每個腳本的安裝與操作說明寫在各自資料夾的 `README.md`。先進到該資料夾再看。

## 不會進版本控制的東西

`.gitignore` 已經擋掉下列項目，clone 下來之後要自己補：

| 項目 | 說明 |
|---|---|
| `.env` | 帳密與組織 ID。複製同資料夾的 `.env.example` 改名後填寫 |
| `browser-profile/` | 瀏覽器登入狀態，第一次執行時自動產生 |
| `node_modules/` | 在該資料夾執行 `npm install` |
| `*.xlsx` | 每期填寫的工作檔。用該資料夾的 `make-template.ps1` 產生空白樣板 |
| `觀察紀錄.md` | 後台流程與 API 的內部筆記，只留在本機 |
