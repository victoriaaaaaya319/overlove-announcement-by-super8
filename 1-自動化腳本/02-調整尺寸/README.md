# 調整尺寸

把方形圖片縮成 960×960 的副本，統一存到這個資料夾底下的 `輸出\`。原檔不會被更動。

## 使用方式

- 把一張或多張圖片**拖曳到 `square_resize.bat` 上**，就會自動處理。
- 直接雙擊 `square_resize.bat`，會開啟檔案選擇視窗，可一次多選。

## 處理規則

| 圖片長寬 | 結果 |
|---|---|
| 長寬相等，或相差 5px 以內 | 建立 960×960 副本存到 `輸出\`，檔名加 `_960`（例如 `封面.jpg` → `輸出\封面_960.jpg`） |
| 相差超過 5px | 不處理，結束時跳出「尺寸比例不符合」視窗，列出檔名與實際尺寸 |

處理完會再跳一個總結視窗，列出建立了哪些副本。副本已存在時會改存為 `_960(2)`，不會覆蓋。

支援 JPG、PNG、WebP、BMP、GIF、TIFF。手機照片會先依 EXIF 方向轉正再判斷。PNG 透明背景保留。

## 第一次設定（換電腦才要做）

1. 安裝 Python 3（Microsoft Store 或 python.org 皆可）。
2. 在 PowerShell 執行：

   ```
   python -m pip install pillow
   ```

## 檔案說明

| 檔案 | 用途 |
|---|---|
| `square_resize.bat` | 拖曳圖片到這裡執行 |
| `square_resize.py` | 腳本本體。要改輸出尺寸、容許誤差或輸出位置，改檔案開頭的 `TARGET`、`TOLERANCE`、`OUT_DIR` |
| `輸出\` | 副本存放處，自動建立。不進版控 |
