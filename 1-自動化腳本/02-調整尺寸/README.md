# 調整尺寸

把圖片縮成固定尺寸的副本，統一存到這個資料夾底下的 `輸出\`。原檔不會被更動。

| 拖到這個檔案 | 輸出尺寸（寬×高） | 副本檔名 |
|---|---|---|
| `square_resize.bat` | 960×960（方形） | `封面.jpg` → `輸出\封面_960.jpg` |
| `portrait_resize.bat` | 960×1553（直式） | `海報.jpg` → `輸出\海報_960x1553.jpg` |

## 使用方式

- 把一張或多張圖片**拖曳到對應的 `.bat` 上**，就會自動處理。
- 直接雙擊 `.bat`，會開啟檔案選擇視窗，可一次多選。

## 處理規則

- 圖片長寬比要符合目標比例才會處理。判斷方式：用原圖寬度換算目標比例下應有的高度，
  跟實際高度相差 5px 以內就直接縮放（方形就是長寬相差 5px 以內）。
- 不符合的圖片不處理，結束時跳出「尺寸比例不符合」視窗，列出檔名與實際尺寸。
- 處理完會再跳一個總結視窗，列出建立了哪些副本。副本已存在時會編號成 `(2)`，不會覆蓋。
- 支援 JPG、PNG、WebP、BMP、GIF、TIFF。手機照片會先依 EXIF 方向轉正再判斷。PNG 透明背景保留。

## 第一次設定（換電腦才要做）

1. 安裝 Python 3（Microsoft Store 或 python.org 皆可）。
2. 在 PowerShell 執行：

   ```
   python -m pip install pillow
   ```

## 要加別的尺寸

複製一個 `.bat`，把裡面的 `--size 960x1553` 改成想要的 `寬x高` 即可，不用改 `resize.py`。

## 檔案說明

| 檔案 | 用途 |
|---|---|
| `square_resize.bat` | 拖曳圖片到這裡 → 960×960 |
| `portrait_resize.bat` | 拖曳圖片到這裡 → 960×1553 |
| `resize.py` | 腳本本體。容許誤差改 `TOLERANCE`，輸出位置改 `OUT_DIR` |
| `輸出\` | 副本存放處，自動建立。不進版控 |
