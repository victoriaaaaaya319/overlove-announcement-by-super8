# Podcast 上稿

把 Podcast《這聲好啊！》的推播自動建成 Super 8 Studio 的群發訊息**草稿**。
由 `01-癡心情報上稿` 改來，操作方式一樣：填 Excel、雙擊 bat。

發送對象腳本**不設定**，草稿建好後自己到 Super 8 選對象、按「計算符合條件的客戶數」→「排程」。

---

## 每期上稿

1. 打開 `Podcast上稿.xlsx`，在「上稿」工作表新增一列。欄位規則寫在「說明」工作表。
2. **存檔、關閉 Excel**。
3. **雙擊 `上稿.bat`**。

   腳本會挑「狀態欄是空白的最後一列」來跑，建好後自動寫入「狀態」和「草稿網址」。
   要重跑某一列，把它的「狀態」清空即可。

只想檢查、不真的建立草稿：`npm run dry`

要指定日期：`node post.js 2026-10-08`

## 訊息內容

| 項目 | 來源 |
|---|---|
| 第 1 則：文字 | Excel「卡片前文字」 |
| 第 2 則：卡片圖片（正方形） | Excel「圖片路徑」 |
| 卡片標題 | Excel「標題」（可在「卡片標題」欄覆寫） |
| 推播通知 | `🎧【這聲好啊！】 ` + Excel「標題」（可在「推播通知」欄覆寫） |
| 卡片敘述 | Excel「卡片敘述」（卡片裡的小字），可留空 |
| 按鈕 1「Apple Podcast 收聽連結」 | Excel「Apple Podcast 網址」 |
| 按鈕 2「Spotify 收聽連結」 | Excel「Spotify 網址」 |
| 按鈕 3「🔔訂閱《這聲好啊！》」 | 回傳文字按鈕，固定；點了上標「【訂閱】這聲好啊！」 |
| 第 3 則：文字 | 固定公版（`config.json` 的 `afterText`）；Excel「卡片後自填文字」有填就用 ♡♡♡♡♡♡♡♡♡♡ 隔開接在後面 |
| 快速回覆 | 顯示文字填 Excel（必填）；回傳內容固定「《這聲好啊！》小心得換小心點」 |
| 發送時間 | Excel「發送日期」+「發送時間」；時間留空 = 21:00 |
| 群發名稱 | `YYMMDD-這聲好啊｜標題` |

固定的東西都在 `config.json`。

## 第一次設定

`.env`（組織 ID、帳密）和登入狀態 `browser-profile/` **直接共用 `01-癡心情報上稿` 那一包**
（`config.json` 的 `sharedDir`），那邊設定好了這邊就不用再設。只需要在這個資料夾裝套件：

```
npm install
```

沒有 `Podcast上稿.xlsx` 的話：

```
powershell -ExecutionPolicy Bypass -File make-template.ps1
```

出問題的排查方式同 `01-癡心情報上稿/README.md`。
