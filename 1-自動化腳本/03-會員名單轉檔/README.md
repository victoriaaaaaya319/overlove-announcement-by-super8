# 會員名單轉檔

把威許後台匯出的「會員基本資料」Excel，轉成只有 Line Uid 的 csv，真金、白銀各一份。
原本的 Excel 不會被更動。

## 使用方式

1. 從威許後台分別匯出真金、白銀的會員資料，檔案留在「下載」資料夾，不用改檔名。
2. **雙擊 `第一階段_會員轉csv.bat`**。
3. 視窗會印出各用了哪個檔、寫出幾筆 uid。csv 存在 `.env` 裡 `OUTPUT_DIR` 指定的資料夾：

   | 級別 | 輸出檔名 |
   |---|---|
   | 真金 | `真金 YYMMDD.csv`（例：`真金 261001.csv`） |
   | 白銀 | `白銀 YYMMDD.csv` |

## 轉完之後整理下載資料夾

確認 csv 沒問題之後，再視需要按這兩顆。順序是**先搬移、再刪除**。

| 雙擊這個檔案 | 做什麼 |
|---|---|
| `第二階段_搬移Excel.bat` | 把這次用到的真金、白銀 Excel（各自最新的一份）從「下載」搬到 `OUTPUT_DIR`，改名成 `會員基本資料_真金_YYYYMMDD.xlsx`、`會員基本資料_白銀_YYYYMMDD.xlsx` |
| `第二階段_刪除Excel.bat` | 把「下載」裡**所有**檔名以 `會員基本資料` 開頭的 `.xlsx` 丟到資源回收筒。會先列出檔名，輸入 `y` 才會刪 |

- 搬移的檔名日期是執行當天。同一天重複搬，會蓋掉當天已搬過去的同級別檔案。
- 刪除是丟資源回收筒，不是永久刪除，誤刪可以從資源回收筒還原。
- 先按刪除再按搬移的話，就沒有檔案可以搬了。

## 上傳到 Super 8（第三階段）

**雙擊 `第三階段_上傳Super8.bat`**，會在 Super 8 Studio 的「客戶中心 → 目標客戶群」各建立一個客戶群：

| 上傳的檔案 | 客戶群名稱 |
|---|---|
| `OUTPUT_DIR` 裡日期最新的 `真金 YYMMDD.csv` | `真金_YYYYMMDD`（例：`真金_20261001`） |
| `OUTPUT_DIR` 裡日期最新的 `白銀 YYMMDD.csv` | `白銀_YYYYMMDD` |

- 匯入方式是 LINE UID。名稱的日期跟著 csv 檔名走。
- 送出後腳本會等 Super 8 比對完名單，再對整個客戶群加標籤：真金加 `【會員】真金工友`，白銀加 `【會員】白銀工友`。
  標籤名稱要改的話改 `upload.js` 的 `LEVEL_TAGS`。
- 標籤以最新名單為準：兩個客戶群都建好之後，每個級別會**先把所有人身上的舊標籤清掉，再加給這次名單裡的人**。
  到期、降級、退會的人不會留著舊標籤。清掉到加回之間有幾秒到幾十秒的空窗，避開群發訊息正在發送的時間再按。
- 最後會把身上有 `【會員】真金工友` 的人的 `【會員】白銀工友` 拿掉（升級的人不會同時帶兩個標籤）。
- 上傳失敗、比對逾時或比對到 0 人時會直接停下來，標籤不會被動到。
- 比對到的人數會比 csv 筆數少，因為 Super 8 裡找不到的 uid（沒加官方帳號等）不會進客戶群。
- 每按一次就會建立一次，**同一天重複按會出現同名的客戶群**。Super 8 的客戶群上限是 10 個，舊的要自己到後台刪。
- 只想看會上傳哪些檔、不真的上傳：在這個資料夾開 PowerShell 跑 `npm run dry`。

## 處理規則

- 來源是「下載」資料夾裡檔名以 `會員基本資料` 開頭的 `.xlsx`，讀第一個工作表。
- 用 F 欄「會員級別」判斷：`1` 是白銀、`2` 是真金。
- 下載資料夾有很多份時，由新到舊找，**每個級別只取最新的一份**。
- 擷取 O 欄「Line Uid」。空白的略過，重複的只留一筆。
- csv 第一行是 `uid`，之後一行一筆。
- 檔名日期是**執行當天**，不是 Excel 的下載日期。同一天重跑會覆蓋當天的 csv。
- 同一個檔裡混了兩種級別，或 F 欄、O 欄的標題不對，該檔會被略過並印出原因。

## 第一次設定（換電腦才要做）

1. 安裝 Python 3（Microsoft Store 或 python.org 皆可）。
2. 在 PowerShell 執行：

   ```
   python -m pip install openpyxl
   ```

3. 複製 `.env.example`，改名成 `.env`，把 `OUTPUT_DIR` 改成 csv 要存的資料夾：

   ```
   OUTPUT_DIR=C:\Users\你的帳號\Documents\會員csv
   ```

   資料夾不存在會自動建立。`.env` 不進版控，每台電腦各填各的。

4. 要用第三階段上傳 Super 8 的話，再多做這幾步：

   - 安裝 Node.js（LTS 版）：`winget install OpenJS.NodeJS.LTS`，裝完關掉終端機再重開。
   - 在這個資料夾執行 `npm install`。
   - 在 `.env` 填上 `SUPER8_ORG_ID`、`SUPER8_EMAIL`、`SUPER8_PASSWORD`（跟 `01-癡心情報上稿` 的 `.env` 一樣）。

   腳本會在背景用這組帳密自動登入，登入狀態存在 `browser-profile/`。
   **`.env` 和 `browser-profile/` 都含登入資訊，不要分享或上傳**（已寫進 `.gitignore`）。
   不想把密碼放檔案的話，`SUPER8_EMAIL` / `SUPER8_PASSWORD` 留空，腳本會開視窗讓你手動登入。

## 出問題的時候

| 症狀 | 處理 |
|---|---|
| `還沒設定檔案要存在哪裡` | 沒有 `.env`，或裡面的 `OUTPUT_DIR` 是空的。照「第一次設定」第 3 步補上 |
| `找不到「會員基本資料」的 Excel 檔` | 確認檔案在「下載」資料夾，檔名開頭沒被改掉 |
| `刪除失敗，可能有檔案正被 Excel 開著` | 關掉 Excel 再按一次 |
| `找不到真金的檔案` / `找不到白銀的檔案` | 那個級別還沒匯出，或匯出時篩選條件選錯了 |
| `略過 …：會員級別不是單一的 1 或 2` | 匯出時沒有篩級別，重新分開匯出 |
| `略過 …：F 欄不是「會員級別」…` | 威許改了匯出欄位，改 `member_csv.py` 的 `LEVEL_COL` / `UID_COL` |

## 檔案說明

| 檔案 | 用途 |
|---|---|
| `第一階段_會員轉csv.bat` | 雙擊執行轉檔 |
| `第二階段_搬移Excel.bat` | 把用到的兩份 Excel 搬到 `OUTPUT_DIR` 並改名 |
| `第二階段_刪除Excel.bat` | 把下載資料夾裡的會員基本資料 Excel 丟到資源回收筒 |
| `第三階段_上傳Super8.bat` | 把最新的真金、白銀 csv 上傳到 Super 8，建立目標客戶群 |
| `member_csv.py` | 第一、二階段的腳本本體。來源資料夾改 `SOURCE_DIR` |
| `upload.js` | 第三階段的腳本本體 |
| `.env.example` | `.env` 的範本 |
| `.env` | 這台電腦的 csv 輸出位置與 Super 8 登入設定。不進版控 |
| `browser-profile/` | Super 8 登入狀態，自動產生。不進版控 |
