# 會員名單轉檔

把威許後台匯出的「會員基本資料」Excel，轉成只有 Line Uid 的 csv，真金、白銀各一份。
原本的 Excel 不會被更動。

## 使用方式

1. 從威許後台分別匯出真金、白銀的會員資料，檔案留在「下載」資料夾，不用改檔名。
2. **雙擊 `會員轉csv.bat`**。
3. 視窗會印出各用了哪個檔、寫出幾筆 uid。csv 存在 `C:\Users\USER\Documents\02-癡情工會\3-會員`：

   | 級別 | 輸出檔名 |
   |---|---|
   | 真金 | `真金 YYMMDD.csv`（例：`真金 261001.csv`） |
   | 白銀 | `白銀 YYMMDD.csv` |

## 處理規則

- 來源是「下載」資料夾裡檔名以 `會員基本資料` 開頭的 `.xlsx`，讀第一個工作表。
- 用 F 欄「會員級別」判斷：`1` 是白銀、`2` 是真金。
- 下載資料夾有很多份時，由新到舊找，**每個級別只取最新的一份**。
- 擷取 O 欄「Line Uid」。空白的略過，重複的只留一筆。
- csv 第一行是 `uid`，之後一行一筆。
- 檔名日期是**執行當天**，不是 Excel 的下載日期。同一天重跑會覆蓋當天的 csv。
- 同一個檔裡混了兩種級別，或 F 欄、O 欄的標題不對，該檔會被略過並印出原因。

## 第一次設定（換電腦才要做）

1. 安裝 Python 3（Microsoft Store 或 python.org 皆可）。
2. 在 PowerShell 執行：

   ```
   python -m pip install openpyxl
   ```

## 出問題的時候

| 症狀 | 處理 |
|---|---|
| `找不到「會員基本資料」的 Excel 檔` | 確認檔案在「下載」資料夾，檔名開頭沒被改掉 |
| `找不到真金的檔案` / `找不到白銀的檔案` | 那個級別還沒匯出，或匯出時篩選條件選錯了 |
| `略過 …：會員級別不是單一的 1 或 2` | 匯出時沒有篩級別，重新分開匯出 |
| `略過 …：F 欄不是「會員級別」…` | 威許改了匯出欄位，改 `member_csv.py` 的 `LEVEL_COL` / `UID_COL` |

## 檔案說明
